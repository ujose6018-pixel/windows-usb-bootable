💿 Windows USB Booteable

Para Chrome OS Flex - Sin terminal complicada

Bienvenido 👋

Esta herramienta te ayudará a crear un USB booteable con Windows de forma sencilla, sin necesidad de usar terminal complicada. Solo necesitas:

  • Un USB de 8GB o más
  • Tu Chrome OS Flex
  • Conexión a internet
  • 20-30 minutos
⚠ Importante: El USB se formateará completamente. Asegúrate de que no tenga datos importantes.

Selecciona tus opciones

ℹ Si no sabes cuál es tu USB: En el siguiente paso te mostraremos un comando para detectarlo automáticamente.

Archivos necesarios

Necesitamos 2 cosas. Descargarlas es automático en el siguiente paso:

📦
Windows 11 ISO
~5GB - Imagen de Windows
🔧
Driver RST NVMe
~100MB - Para que Windows vea tu disco
ℹ Balena Etcher: Es una herramienta gratuita que copia la ISO al USB de forma segura. Se descargará automáticamente.
✓ El proceso total toma ~20 minutos
(Depende de tu velocidad de internet y USB)

Reinicia e instala Windows

                
                

                    ✓ ¡Tu USB está listo!

                    Ahora vamos a instalar Windows en tu HP
                


                
Pasos en tu HP 15s:

                
                
    
                    
  1. Desconecta el USB del Chrome OS Flex
    2. 
                    
  2. Conecta el USB a tu HP
    3. 
                    
  3. Reinicia tu HP: Apaga completamente y enciende
    4. 
                    
  4. Durante el arranque, presiona F2 (rápido, antes de que aparezca Windows)
    5. 
                    
  5. Ve a "System Configuration" (o "Advanced")
    6. 
                    
  6. Busca "Intel VMD" y desactívalo
    7. 
                    
  7. Ve a "Boot Options" y cambia a USB
    8. 
                    
  8. Guarda con F10 y reinicia
    9. 
                    
  9. Arrancará desde el USB - Sigue el instalador de Windows normalmente
    10. 
                    
  10. Si pide driver NVMe: Busca en el USB la carpeta "drivers"
    11. 
                


                

                    ⚠ Recuerda: Es IMPORTANTE desactivar Intel VMD en BIOS. Sin eso, Windows no verá tu disco duro.
